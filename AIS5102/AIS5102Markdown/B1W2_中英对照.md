## 1. 这篇作业在干什么

**English.** You are given a thousand Raman spectra and told nothing about the samples. By the end you will have found that they fall into **three kinds of material**.

**中文。** 老师给你 1000 条拉曼光谱（Raman spectra），一开始不告诉你样品是什么。做完 11 步之后，你会自己发现：这 1000 条其实是 **三类材料**。

一句话故事：

1. 把数据看成一张表（设计矩阵 / design matrix）。
2. 看哪些列在变（信息在标准差大的波数上）。
3. 看哪些列一起变（协方差 / 相关）。
4. 找出变化最大的方向（特征值 / 特征向量）。
5. 把每条光谱投到这些方向上，云团会裂成几堆。
6. 对每一堆求平均光谱，用 D/G、2D/G 说出三类是什么。

在你这套 `b1_data1.npz` 上，三类大致是：

| 类型 type | 条数 n | 物理上是什么 |
|---|---|---|
| 0 | 340 | 石墨烯较多（G、2D 峰强，缺陷比较少） |
| 1 | 379 | 中间：石墨烯覆盖少一些 |
| 2 | 281 | 几乎是裸硅衬底（G、2D 掉到背景） |

### Step 3 — Feature statistics: the first two cumulants（2 分）

#### 卷面英文在说什么

For each column \(k\), compute its mean and spread across the thousand measurements. Both sums are over \(n\), so both are `axis=0`, shape \((W,)\). Use `ddof=1` so \(\sigma\) matches the covariance in Step 6.

对每一列算均值和分散程度。两个都是对 1000 个样品求和，所以都是 `axis=0`，出来形状是 \((W,)\) 不是 \((N,)\)。标准差用 `ddof=1`（除以 \(N-1\)），才能和后面协方差对角线一致。

$$
\mu_k=\frac{1}{N}\sum_n X_{nk},\qquad
\sigma_k^2=\frac{1}{N-1}\sum_n(X_{nk}-\mu_k)^2
$$

#### 代码干什么（`q023`）

```python
def q023(X):
    mu = X.mean(axis=0)          # 每列均值
    sd = X.std(axis=0, ddof=1)   # 每列标准差，无偏
    return mu, sd
```

画图时 x 轴必须是 `axis`（波数），**不要用列序号 0,1,2,…**。两个面板上下叠，**不要共用 y 轴**（均值和标准差单位一样是 counts，但数值范围不同，卷面要求分开标）。

#### 要交什么

- **Plot：** \(\mu_k\)、\(\sigma_k\) 对波数，上下两面板。  
- **Report：** \(\mu\) 的范围，\(\sigma\) 的范围，各自最大处的波数。  
- **Interpret（两句）：**  
  1. 两条曲线在同一处见顶，说明信息在哪里；为什么 \(\sigma\approx 0\) 的列再亮也分不开样品。  
  2. \(\sigma\) 很尖。尖峰是真峰还是坏探测器？只用这张图怎么区分。

#### 这套数据

```
range of mu:    [502.5, 2239.6] counts
range of sigma: [2.44,  226.1 ] counts
max mu and max sigma both at 519.0 cm^-1
```

**English.** Both curves peak at ~519 cm⁻¹, so the information that tells spectra apart lives in a handful of bands. A feature with \(\sigma\) near zero is the same in every row, so a large \(\mu\) is only a constant offset. A \(\sigma\) spike on a \(\mu\) peak and several bins wide is a real band; a single-column spike with no mean peak would be a faulty detector.

**中文。** 两条曲线都在约 519 cm⁻¹ 见顶 → 能把光谱分开的信息，就集中在少数几个峰。某列 \(\sigma\) 接近 0 = 每条光谱这个格子几乎一样，均值再大也只是常数，分不开样品。\(\sigma\) 尖峰如果同时也是 \(\mu\) 的峰、并且占好几个格子 = 真的拉曼峰；如果只有一列在跳、均值没有峰 = 探测器坏了。

### Step 4 — Mean-centre, and check it（1 分）

#### 卷面英文在说什么

Subtract each feature's own mean. Every later step talks about \(\mathbf{X}_c\), not \(\mathbf{X}\). Without centring, covariance is dominated by the fact that all intensities are large positive numbers.

每一列减去自己的均值。后面散度、协方差、相关、特征向量，说的都是去均值后的 \(\mathbf{X}_c\)。不去均值的话，协方差会被「强度都是很大的正数」这件事淹没。

$$
(X_c)_{nk}=X_{nk}-\mu_k
$$

#### 代码干什么（`q024`）

```python
def q024(X, mu):
    return X - mu    # 广播：右边对齐，(N,W) - (W,) 正确
```

`X - mu[:, None]` 会报错，那是广播在保护你。

#### 要交什么

- **Report：** `np.abs(Xc.mean(axis=0)).max()`  
- **Interpret（一句）：** 为什么不是精确的 0？大概多大？为什么 `== 0` 是错的检查？

#### 这套数据

```
np.abs(Xc.mean(axis=0)).max() = 1.86e-13
```

**English.** The residual is ~1e-13: float64 round-off on a sum of ~1000 values of size ~10³. Testing `== 0` fails even when centring is correct.

**中文。** 残差大约 \(10^{-13}\)，是 float64 对「大约 1000 个、大小约 1000 的数」求和时的舍入。去均值是对的，但用 `== 0` 会判失败，因为计算机不是无限精度。

### Step 6 — Scatter, covariance, correlation（4 分，本卷最重）

#### 卷面英文在说什么

Three matrices, each built from the last. All are \((W,W)\): feature against feature.

三个方阵，一个从上一个来。都是特征对特征。

**Scatter 散度** — 对样品求和的乘积：

$$
\mathbf{S}=\mathbf{X}_c^{\mathsf T}\mathbf{X}_c
$$

左边的双重求和就是矩阵乘法，用 `@`，不要写循环。

**Covariance 协方差** — 除掉 \(N-1\) 变成平均（Bessel 修正：Step 3 估均值花掉一个自由度）：

$$
\boldsymbol{\Sigma}=\mathbf{S}/(N-1)
$$

所以 \(\Sigma_{kk}=\sigma_k^2\) 必须精确成立。

**Correlation 相关** — 再除掉每列自己的尺度：

$$
C_{ij}=\Sigma_{ij}/(\sigma_i\sigma_j)
\qquad\text{也就是除以}\quad \sigma\sigma^{\mathsf T}=\texttt{np.outer(sd, sd)}
$$

只除一次 `sd` 会得到不对称、对角线不是 1 的矩阵。这是本步最常见错误。

**不要调用库的相关函数。**

#### 代码干什么（`q026`）

```python
def q026(Xc, sd):
    N = Xc.shape[0]
    S = Xc.T @ Xc                 # 散度
    Sigma = S / (N - 1)           # 协方差
    Corr = Sigma / np.outer(sd, sd)  # 相关
    return S, Sigma, Corr
```

画图：1×3，**各自一条 colorbar**（单位差几个数量级）。用发散色图 `RdBu_r`，`vmin=-m, vmax=+m`，因为协方差的正负号有意义。

#### 要交什么

- **Plot：** 三张图，各有 colorbar。  
- **Report：** 三个形状，以及 \(\operatorname{Tr}(\Sigma)\)（总方差，Step 8 还要用）。  
- **Interpret（两句）：**  
  1. 协方差图和相关图看起来完全不同。哪张能读出「谁和谁一起动」？另一张被什么主宰？  
  2. 相关矩阵对角线以外有亮块，而且 \(i,j\) 可以差几百 cm⁻¹。那是什么意思？

#### 这套数据

```
S, Sigma, Corr 都是 (1024, 1024)
Tr(Sigma) = 683443.34   （等于 sum sigma^2）
```

**English.** Relationships are readable on the **correlation** image; the covariance is dominated by the few high-\(\sigma\) columns (Si and G). A bright off-diagonal block hundreds of cm⁻¹ apart means two distinct Raman bands rise and fall together.

**中文。** 能读「谁和谁一起动」的是**相关图**；协方差图几乎只亮在 \(\sigma\) 最大的那几列（硅和 G）。对角线以外、相隔几百 cm⁻¹ 还很亮 = 两个不同的拉曼峰在样品之间一起升一起降。

#### Step 6a（可选，不占分）

把 \(|C_{ij}|\) 排序，但丢掉 \(|\tilde\nu_i-\tilde\nu_j|<150\) cm⁻¹ 的邻居（同一个峰占很多格子，邻居相关是废话）。

这套数据上活下来的最强一对：**G ≈ 1584 与 2D ≈ 2715，C ≈ 0.99**。

**为什么这两个会一起动：** 都是同一块石墨烯上的碳振动。光斑下石墨烯多，两个峰一起亮；石墨烯少，两个一起暗。

### Step 7 — Eigenvectors of the covariance, computed stably（2 分）

#### 卷面英文在说什么

Along which directions in 1024-dimensional feature space does the data actually extend? Those are the eigenvectors of \(\boldsymbol{\Sigma}\):

$$
\boldsymbol{\Sigma}\mathbf{v}_k=\lambda_k\mathbf{v}_k
\qquad\Longleftrightarrow\qquad
\boldsymbol{\Sigma}=\mathbf{V}\boldsymbol{\Lambda}\mathbf{V}^{\mathsf T}
$$

这就是 Chapter 02 的 **rotate, stretch, rotate（旋转、拉伸、再旋转）**：\(\mathbf{V}^{\mathsf T}\) 把云团的自然轴转到坐标轴，\(\Lambda\) 说每条轴伸多长，\(\mathbf{V}\) 转回去。

**必须用 `np.linalg.eigh`，不要 `eig`。**

| | `eig` | `eigh` |
|---|---|---|
| 假定 | 任意方阵 | **对称**（Hermitian） |
| 返回 | 复数，没有保证顺序 | 实数，**从小到大** |
| 在这个矩阵上 | 虚部约 \(10^{-13}\)（纯舍入），但数组变成复数，后面全坏 | 真正的实数 |

协方差由构造就是对称的，特征值理论上一定是实数。`eigh` 保证升序；你要降序，所以 **特征值和特征向量的列一起倒过来**，否则最大的 \(\lambda\) 会配错方向。

**不要把负数 clip 掉，也不要取绝对值。** 原样返回分解给的数。

#### 代码干什么（`q027`）

```python
def q027(Sigma):
    lam, V = np.linalg.eigh(Sigma)
    lam = lam[::-1]       # 特征值改为从大到小
    V = V[:, ::-1]        # 对应的列一起倒
    return lam, V         # V[:, k] 属于 lam[k]
```

#### 要交什么

- **Report：** 最大的三个特征值；\(\mathbf{V}^{\mathsf T}\mathbf{V}\) 离单位阵的最大绝对偏差（检查标准正交）。  
- **Interpret（一句）：** 最小的一些特征值会略微为负，这对协方差是不可能的。它们其实是什么？为什么题目不许 clip？

#### 这套数据

```
lambda_0 = 602738.42
lambda_1 =  36679.33
lambda_2 =  13885.97
max |V^T V - I| = 4.0e-15
smallest eigenvalue = -1.37e-12
number of negative eigenvalues = 17
```

**English.** The tiny negatives (~1e-12) are floating-point noise on a theoretically PSD matrix. Do not clip: that would hide the numerical fact and break `sum(lambda) = Tr(Sigma)`.

**中文。** 那些微小负数（约 \(10^{-12}\)）是浮点噪声。理论上协方差半正定，不该有负特征值。不要 clip：一 clip 就看不出这件事，而且会破坏「特征值之和 = 迹」这个恒等式。

### Step 8 — The eigenvalue spectrum: how many directions?（2 分）

#### 卷面英文在说什么

Plot \(\lambda_k\) against \(k\) on a **log y axis**. On a linear axis you see one spike and a flat line. A trap: log of a negative number is undefined — either plot \(|\lambda_k|\) or only the leading few dozen, and say which in a comment.

用对数 y 轴画特征值谱。线性轴上你只能看见一根巨柱。陷阱：负数不能取 log。可以画绝对值，或只画前面几十个（都是正的）。注释里写你选了哪一种、为什么。

总方差既是迹，也是特征值之和：

$$
\operatorname{Tr}\boldsymbol{\Sigma}=\sum_k\Sigma_{kk}=\sum_k\lambda_k
$$

前 \(K\) 个方向抓住的方差比例：

$$
f_K=\frac{\sum_{k=1}^{K}\lambda_k}{\sum_{k=1}^{W}\lambda_k}
$$

#### 代码干什么（`q028`）

```python
def q028(lam, target=0.95):
    frac = np.cumsum(lam) / lam.sum()
    K = int(np.searchsorted(frac, target) + 1)
    return frac, K
```

- `frac[k-1]` 就是 \(f_K\)（\(K=k\)）。  
- `K` = 达到 95% 所需的最少方向数。

讲义/笔记本里采用「只画前 80 个」：它们都是正的，对数轴合法，尾巴那些数值负值本来也不是物理。

#### 要交什么

- **Plot：** 左：特征值对数谱；右：\(f_K\) 对 \(K\)，加一条 95% 水平线。  
- **Report：** \(f_1,f_2,f_3,f_5\) 写成百分比，以及 95% 处的 \(K\)。  
- **Interpret（两句）：**  
  1. 一个特征值远大于其余。结合 Step 3，这个方向描述样品的什么？注意它**不是**石墨烯的性质。  
  2. 数据名义上在 1024 维。它实际上占了几维？设计矩阵里有多少列在做无用功？

#### 这套数据

```
f_1 = 88.19 %
f_2 = 93.56 %
f_3 = 95.59 %
f_5 = 97.08 %
K at 95% target = 3
```

**English.** The leading eigenvalue is Si substrate intensity near 519 cm⁻¹, not a graphene property. The data nominally live in 1024 dimensions but **3** directions already hold 95% of the variance, so almost all columns were redundant.

**中文。** 最大的那个方向是约 519 cm⁻¹ 的**硅衬底**强度，不是石墨烯。名义 1024 维，真正有用的大约 **3** 维就抓住 95% 方差——设计矩阵里绝大多数列是多余的。

### Step 9 — What does an eigenvector look like?（1 分）

#### 卷面英文在说什么

Each \(\mathbf{v}_k\) has shape \((W,)\) — the same as a spectrum. So plot it as one, against `axis`, with bands marked. An eigenvector is a pattern of co-variation: when this sample differs from the average, these bins go up together and those go down together.

每个特征向量形状和一条光谱一样，所以就当光谱来画。它不是抽象箭头，而是一套「共变配方」：这个样品比平均更如何时，哪些格子一起升、哪些一起降。

#### 代码干什么

没有新函数。用 Step 7 的 `V`：

```python
for k in range(3):
    ax.plot(axis, V[:, k] + k * 0.45)   # 上下错开，免得重叠
```

#### 要交什么

- **Plot：** \(v_0,v_1,v_2\) 对波数，错开，五个峰标上。  
- **Report：** 每个向量 \(|v|\) 最大的五个波数，带峰名。  
- **Interpret（一句）：** 三个向量互相正交 \(\mathbf{v}_i^{\mathsf T}\mathbf{v}_j=\delta_{ij}\)，却都压在重叠的峰上。两件事怎么能同时成立？正交禁止什么、不禁止什么？

#### 这套数据（最大的 \(|v|\) 落点）

- \(v_0\)：519（硅）、1580（G）、1584（G）…  
- \(v_1\)：523、519（硅）、2677（2D）…  
- \(v_2\)：还是硅和 G 一带  

**English.** Orthogonality constrains the inner product of the **whole** vectors, not which bands they may touch. They can share support as long as the signed weights cancel (one vector +G/−Si, another +Si/+2D).

**中文。** 正交限制的是**整条向量的点积**，并不禁止它们碰到同一批峰。只要有的格子为正、有的为负，点积仍可以是 0。例如一个是 +G −硅，另一个是 +硅 +2D。

### Step 10 — Project the spectra, and look at the cloud（2 分）

#### 卷面英文在说什么

Each row of \(\mathbf{X}_c\) is a point in 1024 dimensions. Step 8 said only a handful of directions matter, so give each spectrum its coordinates along those directions:

$$
\mathbf{P}=\mathbf{X}_c\,\mathbf{V}_{:,1:K}
$$

\(\mathbf{P}\) 形状 \((N,K)\)：还是一行一条光谱，但只剩 \(K\) 个数。没有拟合、没有学习，只是换坐标系，把同一团云转一下。

检查投影对不对：

$$
\operatorname{Var}(P_{:,d})=\lambda_d
$$

对不上，多半是：投了没有去均值的 `X`，或 Step 7 没有把顺序改成从大到小。

#### 代码干什么（`q0210`）

```python
def q0210(Xc, V, n_components=3):
    return Xc @ V[:, :n_components]
```

Pair plot：3×3。对角线画每个坐标的直方图，其余格子画散点。每个面板要有轴标签。

#### 要交什么

- **Plot：** 前三个坐标的 pair plot。  
- **Report：** `P.shape`，以及 \(d=0,1,2\) 时 \(\operatorname{Var}(P_{:,d})\) 对 \(\lambda_d\)。  
- **Interpret（一句）：** 云不是一个团。你看见几堆？哪一个面板分得最开？有没有哪一对坐标比第一坐标单独分得更好？

#### 这套数据

```
P.shape: (1000, 3)
Var(P[:,0]) = 602738.42 = lambda_0
Var(P[:,1]) =  36679.33 = lambda_1
Var(P[:,2]) =  13885.97 = lambda_2
```

**English.** The cloud is not a single blob. Two dense lobes (with a thin bridge) plus a tight linear satellite at high \(P_{:,0}\) separate most clearly in every panel that includes \(P_{:,0}\). No later pair beats the first coordinate alone.

**中文。** 不是一坨。两团比较密（中间有细桥），另外在很大的 \(P_{:,0}\) 处还有一条细细的线状卫星。**凡是带第一坐标的面板**分得最清楚。后面两个坐标的组合，没有比单用第一坐标分得更好。

#### 卷面英文在说什么

Split into **three approximate types** using a threshold on the coordinate you named in Step 10. Your split does not have to match anyone else's — the cloud has two dense lobes with a thin bridge, so where you cut the bridge is a judgement call.
