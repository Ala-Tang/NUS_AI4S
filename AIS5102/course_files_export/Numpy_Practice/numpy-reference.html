Quickstart

A fast, hands-on tour of the NumPy you need for the easy and medium exercises — arrays as tensors, indexing, broadcasting, the axis argument, matrix products, and the modern random API. Every snippet is meant to be typed into a notebook. Hover any np.array-style chip anywhere on this page to preview its reference card.

1. Setup and creating arrays

NumPy's one object is the N-dimensional array (ndarray): a contiguous, typed buffer plus a shape. In ML this object is the tensor — a design matrix is (n_samples, n_features), a batch of images is (batch, H, W, channels). Learning to think in shapes is the transferable skill. Maps to tasks 1–5, 29.

import numpy as np                     # universal convention

np.array([1, 2, 3])                    # from a Python list -> shape (3,)
np.array([[1, 2, 3], [4, 5, 6]])       # nested lists -> shape (2, 3)

np.zeros((2, 3))                       # all zeros
np.ones((2, 3))                        # all ones
np.full((2, 4), 7.0)                   # constant fill
np.eye(3)                              # 3x3 identity

np.arange(0, 10, 2)                    # like range(): [0 2 4 6 8], step-based
np.linspace(0, 1, 50)                  # 50 points 0..1 INCLUSIVE, count-based

2. Shape, dtype, reshaping, axes

Every array carries shape, dtype, ndim, and size. Reshaping and transposing mostly rearrange the interpretation of the buffer, not the bytes. Add a length-1 axis with np.newaxis to make a vector broadcast as a row or column. In ML, prefer float32 for data/weights (half the memory, GPU-friendly) and float64 for accumulations. Maps to tasks 6, 11, 12, 15, 33, 50.

M = np.arange(12).reshape(3, 4)        # (3, 4) view over the same 12 numbers
M.shape, M.ndim, M.size, M.dtype       # (3,4), 2, 12, dtype('int64')

M.reshape(2, -1)                       # -1 = infer -> (2, 6)
M.ravel()                              # flatten to 1-D
M.T                                    # transpose -> (4, 3)

v = np.array([1, 2, 3])                # shape (3,)
v[:, np.newaxis]                       # column vector, shape (3, 1)

imgs = np.zeros((32, 28, 28))          # batch of 32 images
imgs.reshape(32, -1).shape             # flatten each -> (32, 784)

M.astype(np.float32)                   # cast dtype (returns a new array)

3. Indexing, slicing, and boolean masks

Give one index per axis. A basic slice is a view (shares memory); boolean masks and fancy (integer-array) indexing return copies. Masking is the workhorse for filtering and cleaning data. Maps to tasks 22, 23, 47.

a = np.array([10, 20, 30, 40, 50])
a[1:4]                                 # [20 30 40]  (stop exclusive)
a[::-1]                                # reversed

M = np.arange(12).reshape(3, 4)
M[1, 2]                                # single element (row 1, col 2)
M[:, 1]                                # whole 2nd column
M[0:2, 1:3]                            # a sub-block (a view)

data = np.array([3.0, -1.0, 4.0, -5.0])
data[data > 0]                         # boolean mask -> [3. 4.]  (a copy)
data[data < 0] = 0.0                   # scatter-assign through a mask

X = np.arange(20).reshape(5, 4)
X[[0, 2, 4]]                           # fancy indexing: gather rows 0,2,4

4. Element-wise math and ufuncs

Arithmetic is element-wise and vectorized — no Python loop. The functions doing this (np.exp, np.sqrt, +, *, …) are universal functions. A for loop over elements is almost always the wrong tool. Maps to tasks 7, 16, 17, 28, 30, 32.

x = np.array([1.0, 2.0, 3.0])
x + 100                                # scalar broadcasts to every element
x ** 2                                 # [1. 4. 9.]
np.sqrt(x); np.exp(x); np.log(x)       # element-wise transcendentals
np.abs([-1.0, 2.0]); np.round([1.4, 1.6])
np.clip(x, 1.5, 2.5)                   # clamp into [1.5, 2.5]
np.where(x > 2, x, 0.0)                # conditional select (vectorized if/else)

5. Aggregations and the axis argument

The key idea: axis=k names the dimension that gets eliminated. From shape (2, 3), axis=0 leaves (3,) and axis=1 leaves (2,). Add keepdims=True to keep the collapsed axis as length 1 so the result stays broadcastable — essential for normalization. Maps to tasks 8–10, 26, 27, 37, 38.

X = np.array([[1, 2, 3], [4, 5, 6]])   # (2, 3)
X.sum()                                # 21  (scalar)
X.sum(axis=0)                          # [5 7 9]  -> per column, shape (3,)
X.sum(axis=1)                          # [6 15]   -> per row,    shape (2,)
X.mean(axis=0); X.std(axis=0); X.max(axis=1)
X.argmax(axis=1)                       # index of max per row

probs = np.array([[0.1, 0.7, 0.2], [0.8, 0.1, 0.1]])
probs / probs.sum(axis=1, keepdims=True)   # row-normalize (keepdims!)

6. Broadcasting

Broadcasting combines arrays of different shapes without loops: align shapes from the right; axes are compatible if equal or one is 1; a length-1 axis is stretched. The canonical use is standardizing a data matrix — subtract the per-feature mean and divide by the per-feature std. Maps to tasks 36, 64.

X = np.array([[1., 100.], [2., 200.], [3., 300.]])   # (3, 2): 3 samples, 2 features
mu = X.mean(axis=0)                    # (2,) per-feature mean
sd = X.std(axis=0)                     # (2,) per-feature std
Xz = (X - mu) / sd                     # (3,2) - (2,) broadcasts over rows
Xz.mean(axis=0)                        # ~[0. 0.] each feature now zero-mean

7. Linear algebra

Element-wise * is not matrix multiplication — use @ (or np.matmul/np.dot). A neural-net linear layer y = X W + b is one line applied to a whole batch. Prefer np.linalg.solve(A, b) over inv(A) @ b — faster and more accurate. Maps to tasks 18, 39, 48, 53.

A = np.array([[1., 2.], [3., 4.]])
x = np.array([1., 1.])
A @ x                                  # matrix-vector -> [3. 7.]
A @ A                                  # matrix-matrix product
x @ x                                  # dot product -> 2.0

X = np.random.default_rng(0).normal(size=(4, 3))
W = np.ones((3, 2)); b = np.array([0.5, -0.5])
Y = X @ W + b                          # (4,3)@(3,2) + bias -> (4, 2)

np.linalg.norm(X, axis=1)              # L2 norm of each row
np.linalg.solve(A, x)                  # solve A z = x  (never inv!)

8. Random numbers (modern Generator API)

Use np.random.default_rng(seed) for a Generator; the seed makes results reproducible. Avoid the legacy global np.random.rand/seed — its hidden shared state makes experiments fragile. Maps to tasks 25, 62.

rng = np.random.default_rng(42)        # same seed -> same numbers
rng.random((2, 2))                     # uniform [0, 1)
rng.normal(0, 1, size=5)               # standard normal
rng.integers(0, 10, size=5)            # ints in [0, 10)
rng.permutation(5)                     # random ordering of 0..4 (shuffle a dataset)

9. Gotcha: views vs copies

Because slices share memory, an innocent assignment can mutate data you did not mean to touch. Basic slicing → view; boolean/fancy indexing → copy. Take .copy() at function boundaries, and use np.shares_memory(a, b) when in doubt.

a = np.arange(5)                       # [0 1 2 3 4]
b = a[1:4]                             # a VIEW into a
b[0] = 99                             # writes through...
a                                      # [ 0 99  2  3  4]  <- a changed!

c = a[1:4].copy()                      # independent copy
c[0] = -1                              # a is untouched

10. Saving and loading

Prefer the binary .npy/.npz formats for round-tripping NumPy data (they preserve dtype and shape exactly); reserve CSV for interchange.

A = np.arange(12).reshape(3, 4)
np.save('A.npy', A);       B = np.load('A.npy')
np.savez('data.npz', train=A, test=B)
np.savetxt('A.csv', A, delimiter=',')
np.loadtxt('A.csv', delimiter=',')     # or np.genfromtxt for gaps
